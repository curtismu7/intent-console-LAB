# intent-console-lab

Demo-tier standalone app: the Privilege console's AI Intents page as a simulation — console-shaped intent CRUD (Exemplars, Twins, Patterns, Acts, Floor), a per-app `modelAIIntentConfig`, and a lab-invented resolution engine over a stand-in encoder on the KServe v2 wire.

- Run: `./scripts/run.sh` (http://localhost:7825). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track`. Content pack: `npm run content-pack`.
- Core: `server/src/intents.js` (the AIIntent store, console shapes, validation with twin warnings), `encoder.js` (hashed character-trigram vector, 384 dims, cosine; KServe v2 `model_info`/`infer` shapes), `resolver.js` (score → Floor → Twins → Acts → FailClosed; each step a labelled hop), `appConfig.js` (`modelAIIntentConfig` validation, loopback-only encoder URL), `story.js` (facts with measured/UNVERIFIED status, six scenarios the doctor replays), `doctor.js` (also runs every scenario through the engine).
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard) — there is NO live mode, `INTC_MODE_REAL=1` only enables the rule-19 Real switch; only `.invalid`/`.example` hosts; one port, 7825; `POST /api/mode` is exactly `{ source: "mock"|"real" }` and switches at runtime (409 + reason when Real is not enabled); intents/config/decisions are per workspace (rule 13).
- Honesty rule: the shapes are measured (console swagger, 2026-11-18); the engine mapping (Floors, Twins, Acts, FailClosed) is UNVERIFIED and must stay labelled that way. The tenant had zero intents — every seed intent is lab-authored. Do not upgrade a claim without re-measuring.
- Engine semantics (do not weaken): twins both over their floors within 0.05 → deny (ambiguous), regardless of fail-open; empty IntentIDs → deny under fail-closed ("no intents selected"), never "empty means all"; Acts=false matched → deny as read-only; an intent with zero exemplars cannot match (create refuses it).
- Web: `web/src/App.jsx` (five tabs, presenter, Reset, runtime Mock/Real toggle), `components/` IntentTable, IntentForm, Resolver, EncoderProbe, Banner, DiagramTab + PatternDiagram (scaffold). Colours from `tokens.css` only; JSON through the shared JsonPane (rule 24).
